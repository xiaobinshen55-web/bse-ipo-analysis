# 北交所打新分析系统

## 项目概述

从东方财富 API 自动获取北交所新股数据，生成可视化 HTML 分析报告，用于向客户推荐低风险打新策略。

```
└── update_bse_ipo.py          更新脚本（拉取API数据，刷新Excel和HTML）
```

## HTML 报告功能

### 数据获取
- 打开时自动从东方财富 API 拉取最新数据（支持 CORS）
- API 不可用时自动降级为 HTML 内嵌的离线缓存数据
- 右上角显示数据来源标签：`实时数据`（绿色）/ `离线缓存`（黄色）

### 筛选规则
- 自动筛选**申购日 ≥ 当天日期 - 185天**的北交所（920开头）新股
- 随时间推移自动滚动，始终保持近半年数据

### 报告章节
1. **什么是北交所打新** — 4步流程图 + 规则要点表格
2. **核心数据概览** — 6个统计卡片（首日涨幅、破发数、获利、PE、中签率、冻结资金）
3. **收益深度分析** — 首日涨幅饼图、发行价柱状图、TOP10收益表、长期持有水平柱状图
4. **月度趋势** — 发行量+冻资双轴图、涨幅+获利双轴图、月度详表
5. **优劣势评估** — 6大优势 vs 6大劣势对比
6. **策略建议** — 操作建议 + 进阶策略
7. **完整数据附表** — 全部股票的明细表格

### 图表类型（全部纯 SVG，无外部依赖）
- 环形饼图（首日涨幅分布）
- 柱状图（发行价格分布）
- 水平柱状图（长期持有累计涨幅 TOP8）
- 双轴组合图 ×2（月度发行+冻资、月度涨幅+获利）

## API 接口详情

| 参数 | 值 |
|------|-----|
| 地址 | `https://datacenter.eastmoney.com/api/data/v1/get` |
| reportName | `RPT_NEEQ_ISSUEINFO_LIST` |
| 过滤 | `(APPLY_DATE>='2025-08-01')` |
| CORS | `Access-Control-Allow-Origin: *` |

### 关键字段映射

| API字段 | Excel列 | 说明 |
|---------|---------|------|
| SECURITY_CODE | 代码 | |
| SECURITY_NAME_ABBR | 简称 | |
| ISSUE_PRICE | 发行价格(元) | |
| ONLINE_ISSUE_LWR | 中签率 | API返回百分比值，需÷100 |
| LD_CLOSE_CHANGE | 涨幅 | API返回百分比值，需÷100转小数 |
| PER_SHARES_INCOME | 每百股获利(元) | |
| APPLY_AMT_100 | 稳获百股所需资金 | API返回元，需÷10000转万元 |
| VA_AMT | 参与申购资金 | API返回元，需÷1e8转亿元 |
| ORG_VAN | 参与申购人数 | API返回户数，需÷1e4转万人 |
